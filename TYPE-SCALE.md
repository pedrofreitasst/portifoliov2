# Type scale

Base **20px**, ratio **1.25** (major third).

| Token | px (approx) | Use |
|---|---|---|
| `text-meta` | 14 | copyright / tiny labels |
| `text-body` / `text-nav` / `text-base` / `text-sm`* | 20 | body, hero sub, nav, chips |
| `text-ui-lg` | 22 | footer links, Let’s Talk |
| `text-title` | 28 | project titles |
| `text-section` / `text-section-lg` | 32–44 | section heads |
| `text-display` | 44–68 | hero H1 |

\* `text-sm` / `text-base` remapped to 20 on this project so nothing important sits at the old 14/16 defaults.

Hero “Made for you, with love.” shares `text-body` with a `<br />`.
